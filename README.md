# GenLink 使用说明

这份说明写给第一次使用 GenLink 的用户。目标是让你知道：怎么启动、怎么配置、怎么创建节点、怎么连线、怎么生成内容、怎么保存和找回文件。

先记住一个核心概念：

> GenLink 是一张可以自由摆放节点的 AI 创作画布。节点就是一个功能卡片，连线就是把上一个节点的内容交给下一个节点使用。

GenLink 基于 Next.js + React Flow + Three.js 构建，支持文本、图像、视频、360 全景图等多种 AI 节点，所有生成产物都保存在你本地选择的项目目录里。

---

## 1. 快速开始

### 1.1 启动软件（源码运行）

GenLink 目前以源码方式运行，需要 Node.js 环境。

1. 安装依赖：

```bash
npm install
```

2. 生成 Prisma 客户端（国内建议走镜像，否则下载引擎可能卡住）：

```bash
PRISMA_ENGINES_MIRROR=https://registry.npmmirror.com/-/binary/prisma npx prisma generate
```

3. 启动开发服务：

```bash
npm run dev
```

4. 打开浏览器访问：

```text
http://localhost:3000
```

进入首页后，点击进入按钮就会来到「项目库」。

### 1.2 第一次必须配置 API Key

GenLink 本身是画布工具，真正生成文本、图片、视频时需要调用对应平台的模型，所以第一次使用通常要先配置 API Key。

入口：

1. 进入画布后，点击左侧工具栏最下方的「设置」按钮。
2. 在「API Key」页面找到你要使用的服务商。
3. 填写对应的 API Key。
4. 点击「保存」。

支持的服务商：

| 服务商 | 常见用途 |
| --- | --- |
| Comfly | 文本、图像、视频 |
| VibeAPI | 文本、图像 |
| Fucheers API | 文本、图像 |
| RunningHub | 图像、工作流（需额外填写「工作流 API Key」） |
| Grsai | 图像 |
| 真真 AI 工坊 | 文本、图像 |

示例只写成这样：

```text
sk-xxxxxxxxxxxxxxxx
```

说明：

- 每个服务商的 API Key 是分开填写的，具体用哪个服务商和模型，在文本节点、图像节点、视频节点里各自选择。
- 视频生成目前走 Comfly。
- RunningHub 除了普通 API Key，还需要单独填写「RunningHub 工作流 API Key」才能跑工作流。
- 不要把自己的真实 API Key 发给别人，也不要公开截图包含 Key 的设置页面。

### 1.3 保存第一个项目

GenLink 用浏览器的文件系统访问能力，把项目直接存到你选择的本地文件夹。

新建项目时：

1. 在项目库点击「开始创作」。
2. 填写项目名称。
3. 点击「浏览」选择一个父目录，系统会在其中创建与项目同名的文件夹。
4. 点击「创建并进入」。

进入画布后，随时可以按：

```text
Ctrl + S
```

保存当前画布。生成出来的图片、视频会单独存到项目目录下的 `output/` 文件夹。

## 2. 界面认识

### 2.1 项目库

启动后先看到项目库。这里可以：

- 开始创作：新建项目。
- 打开已有项目卡片：进入对应画布。
- 卡片右上角菜单：打开、重命名、创建副本、删除项目。
- 批量导入：选择一个父目录，一次性导入其中的多个项目文件夹。

### 2.2 顶部区域

进入画布后，左上角是项目入口。

- 项目名称：点击可以重命名。
- Logo 菜单（悬停展开）：回到项目库、新建项目、删除项目。

### 2.3 左侧工具栏

左侧竖排工具栏是最常用入口，从上到下：

- 添加（加号）：悬停展开「添加节点」菜单，创建文本、图像、360 全景图、视频、音频、分镜格子，或上传素材。
- 素材库：管理可复用的图片素材。
- 列表 / 消息：占位入口。
- 历史：查看本项目生成过的图片和视频。
- 保存：保存当前项目。
- 设置：配置各平台 API Key。

### 2.4 中间画布

中间就是创作区域。你可以在这里：

- 放置和拖动节点。
- 缩放和平移视图。
- 连接节点。
- 查看生成结果。

画布很大，如果节点找不到了，按 `G` 重置视图、把节点拉回视野。

### 2.5 左下角控制

左下角常见控制：

- 小地图：查看节点整体位置，可点击开关。
- 连线样式：在直线和曲线之间切换。
- 重置视图：自动把节点拉回视野（快捷键 `G`）。
- 缩放滑杆：调整画布显示大小。

## 3. 基础操作

### 3.1 创建节点

常用方式：

1. 鼠标移到左侧「添加」按钮，弹出节点菜单。
2. 选择节点类型，节点会出现在画布上。

也可以：

- 在画布空白处双击，直接在该位置弹出添加菜单。
- 把图片直接拖进画布，或用 `Ctrl + V` 粘贴剪贴板里的图片，系统会自动创建上传图像节点。

### 3.2 移动画布和节点

- 鼠标滚轮：缩放画布。
- 按住空格拖动：平移画布。
- 拖动节点：移动节点。
- 在空白处框选：选中多个节点。
- 拖动多个节点后松手：可形成分组框（按 `G` 相关操作整理）。

### 3.3 连线

连线表示「把一个节点的结果交给另一个节点使用」。

常规步骤：

1. 找到上游节点，例如一张参考图。
2. 从它边缘的连接点拖到下游 AI 节点。
3. 下游节点会收到这个参考内容，通常会显示参考缩略图。

也可以选中节点后，点节点工具栏里的「连接节点」按钮，再点目标节点完成连接。

常见用法：

- 上传图像 / 生成图像 -> AI 图像生成节点（作为参考图）。
- 生成图像 -> AI 视频生成节点（图生视频）。
- 文本节点 -> AI 图像 / 视频节点（作为提示词来源）。
- 生成图像 -> 360 全景图节点。

### 3.4 导入和导出项目

GenLink 的项目是文件夹形式，不是单个 JSON：

- 导入：在项目库用「批量导入」，选择包含项目文件夹的父目录。
- 迁移：直接复制整个项目文件夹即可，里面包含画布数据和 `output/` 生成结果。

## 4. 节点类型

### 4.1 源 / 上传节点

| 节点 | 用途 |
| --- | --- |
| 文本节点 | 放剧情、提示词、角色设定、文案，也可作为 AI 文本生成的输入 |
| 上传图像 | 拖入或粘贴的图片，常作为参考图 |
| 上传视频 | 拖入的视频素材，可作为视频生成参考 |

### 4.2 AI 生成节点

| 节点 | 用途 |
| --- | --- |
| 文本节点（生成） | 写文案、总结、改写、提取信息；可连接图片做图生文 |
| 图像生成 | 文生图、图生图、海报、角色图、场景图 |
| 视频生成 | 文生视频、图生视频、首尾帧、全能参考 |
| 360 全景图 | 生成可交互查看的 360 全景场景 |

基本流程都差不多：

1. 创建 AI 节点。
2. 在节点底部的提示词栏选择服务商和模型。
3. 输入提示词。
4. 需要参考素材时，把上游节点连进来。
5. 点击生成（运行按钮）。

> 注：添加菜单里的「音频」「分镜格子」为占位入口，当前版本主线能力是文本、图像、视频、360 全景图。

### 4.3 图像生成节点的参数

在图像生成节点的提示词栏里，可以设置：

- 服务商与模型（如 gpt-image-2、Nano banana pro 等，随服务商不同而变化）。
- 画幅比例：自适应，或 1:1、16:9、9:16 等多种比例。
- 清晰度档位：1K / 2K / 4K。
- 输出格式：PNG / JPEG / WebP。
- 并行数量：一次生成 1、2 或 4 张。

### 4.4 视频生成节点的参数

- 模型：seedance 2.0 / seedance 2.0 fast（走 Comfly）。
- 生成模式：文生视频、图生视频、全能参考、首尾帧。
- 画面比例：16:9、4:3、1:1、3:4、9:16、21:9。
- 分辨率：480p / 720p / 1080p。
- 时长：4 到 15 秒。
- 可选项：是否生成音频等。

视频生成通常比图片更慢，也更消耗额度，生成时不要频繁刷新页面。

## 5. 一个完整的新手流程

下面用「参考图生成海报，再生成视频」举例。

### 5.1 上传参考图

把一张图片拖进画布，或用 `Ctrl + V` 粘贴。系统会创建上传图像节点。

### 5.2 创建图像生成节点

1. 鼠标移到左侧「添加」，选择「图像」。
2. 画布上出现 AI 图像生成节点。

### 5.3 连接参考图

把上传图像节点连到图像生成节点。连接成功后，图像节点的提示词栏里会显示参考图缩略图。

### 5.4 输入提示词

示例：

```text
电影海报风格，雨夜城市，人物站在霓虹灯下，神秘、悬疑、高级质感，画面清晰，光影丰富。
```

提示词可以按这个思路写：

- 主体：画面里有什么。
- 场景：在哪里。
- 风格：写实、电影感、插画、海报等。
- 氛围：温暖、悬疑、梦幻、未来感等。
- 质量：清晰、细节丰富、光影自然。

### 5.5 点击生成

选好服务商和模型后点击运行。图片生成完成后会显示在节点中，文件会保存到项目目录的 `output/`。

### 5.6 继续生成视频

1. 创建视频生成节点。
2. 把生成的图片连到视频节点。
3. 选择「图生视频」模式，输入视频提示词。

示例：

```text
镜头缓慢推进，人物轻轻转头看向远方，雨水落下，霓虹灯反光，电影感，动作自然。
```

### 5.7 保存项目

按 `Ctrl + S` 保存。建议用清楚的名字，例如：

```text
雨夜侦探海报和视频_v1
```

## 6. 提示词与 `@` 引用

### 6.1 提示词

提示词就是你告诉 AI 的要求。文本、图像、视频节点都有各自的提示词栏，支持展开 / 收起以输入长文本。

### 6.2 `@` 引用

在提示词输入框输入 `@`，可以引用已连接进来的图片或视频。

适合：

- 在一句话里点名引用第几张参考图。
- 让生成结果明确对应某个上游素材。

例子：

```text
请参考 @图片1 的服装风格，生成角色半身设定图，写实电影感。
```

### 6.3 连线和 `@` 怎么选

简单记：

- 图片、视频这类素材，先用连线接进来。
- 连进来之后，如果要在文字里精确点名某一张，再用 `@` 引用。
- 不确定时先用连线，因为提示词栏里能直接看到引用缩略图。

## 7. 节点工具栏

选中节点后，节点附近会出现工具栏。不同节点的工具不同。

### 7.1 图像生成节点

生成出图片后，常见能力：

- 裁剪：截取图片的一部分。
- 分割：宫格裁剪（2x2、3x3、5x5）。
- 360 全景图：基于当前图生成全景图节点。
- 3D 视角：进入 3D 视角调整。
- 加入素材库：把图片存为可复用素材。
- 下载：保存图片。
- 放大查看：全屏预览。

没有图片时，节点上会显示「上传」按钮，用来放参考图。

### 7.2 视频生成节点

生成出视频后，常见能力：

- 下载：保存视频。
- 放大查看：全屏预览。
- 加入素材库 / 复制链接等。

### 7.3 文本节点

文本节点工具栏常用：

- 背景色：给文本卡片换底色，便于整理画布。
- 标题层级：H1 / H2 / H3 / 正文。
- 复制内容。

### 7.4 通用节点工具栏

多数节点选中后还会有通用工具栏：复制、连接节点、分享、更多、删除。

## 8. 项目、素材库与历史

### 8.1 项目

项目就是当前画布内容，保存到你创建时选择的本地文件夹。建议项目名写清楚，例如：

```text
短剧_人物设定_v1
产品海报_主视觉_v2
图生视频测试_雨夜场景
```

### 8.2 素材库

素材库用于保存可复用的图片素材，按分类管理：

- 分类：人物、场景、物品、风格、其他。
- 用法：选中图像节点，从工具栏「加入素材库」存入；之后从左侧「素材库」面板挑选并拖回画布。

### 8.3 历史

左侧工具栏的「历史」会列出本项目生成过的图片和视频，按日期分组。可以从历史里重新取回某次生成的结果。

## 9. 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + S` | 保存项目 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` | 重做 |
| `Ctrl + C` | 复制选中节点 |
| `Ctrl + V` | 粘贴节点 / 粘贴剪贴板图片 |

## 10. 文件保存在哪里

GenLink 把项目存成一个文件夹（通过浏览器的文件系统访问能力），主要内容：

| 位置 | 保存什么 |
| --- | --- |
| 项目文件夹根目录 | 画布结构、节点、连线、提示词等（`project.json`） |
| `output/` | AI 生成的图片、视频，以及生成历史（`history.json`） |

提醒：

- 不要随便删除 `output/`。如果删掉，画布数据还在，但节点可能找不到对应的图片或视频。
- 要完整备份或迁移项目，直接复制整个项目文件夹即可。
- 分享项目时最好整个文件夹一起给，否则对方可能看不到图片和视频。

可选的图床配置：如果你想让图片有公网 URL（用于外部分享或投递），可以在 `.env` 里配置阿里云 OSS：

```bash
ALIYUN_OSS_BUCKET="your-bucket"
ALIYUN_OSS_REGION="cn-hangzhou"
ALIYUN_OSS_ACCESS_KEY_ID="your-access-key-id"
ALIYUN_OSS_ACCESS_KEY_SECRET="your-access-key-secret"
ALIYUN_OSS_PUBLIC_BASE_URL="https://your-cdn-or-bucket-domain"
```

不配置 OSS 也能正常使用，默认走本地图床。

## 11. 常见问题

### 11.1 页面打不开

检查：

- `npm run dev` 是否正在运行。
- 浏览器地址是否是 `http://localhost:3000`。
- 终端有没有报错。

### 11.2 生成失败

优先检查：

- 对应平台的 API Key 是否在「设置」里填写并保存。
- 选择的模型是否属于你已配置 Key 的服务商。
- 平台余额或权限是否足够。
- 用 RunningHub 工作流时，是否填了「工作流 API Key」。

### 11.3 配了 Key 还是报错

常见原因：

- 粘贴时多了空格。
- 填错了服务商。
- Key 已失效。
- 参考图太多或太大（提示 request entity too large）：减少参考图数量或先压缩。

### 11.4 图片或视频不显示

可能是文件被移动或删除了。先检查项目目录下的 `output/` 里对应文件是否还在。文件还在就刷新页面；文件没了只能从备份恢复或重新生成。

### 11.5 无法选择项目目录

GenLink 用的是浏览器文件系统访问能力，建议用较新版本的 Chrome / Edge。选择目录后浏览器会请求授权，需要同意。

### 11.6 提示有新版本

右下角出现「发现新版本」时，点「刷新」会先自动保存当前画布再重新加载，避免丢失进度。

## 12. 推荐学习顺序

新手建议按这个顺序学：

1. 启动服务，进入项目库，新建并进入一个项目。
2. 在「设置」里配置至少一个服务商的 API Key。
3. 创建图像生成节点，生成一张图。
4. 上传参考图，连到图像节点，做一次图生图。
5. 把生成图连到视频节点，做一次图生视频。
6. 学会 `Ctrl + S` 保存，知道文件在项目目录的 `output/`。
7. 用文本节点、背景色和分组整理画布。
8. 学素材库和历史，复用常用素材、找回历史生成。
9. 再尝试裁剪、宫格分割、360 全景图、3D 视角等进阶工具。

不用一开始就掌握所有功能。先跑通「创建节点 -> 写提示词 -> 连线 -> 生成 -> 保存」这一条主线，就已经能完成大部分基础创作了。
