# 画布新建命名与当前画布标识设计

## 目标

改进左上角画布切换菜单的创建反馈和当前项辨识：用户点击“新建画布”后先在菜单内确认名称，提交后才写入项目；创建过程中显示现有的画布进入加载动画；当前画布在列表中常驻显示勾选标识，并在悬停或键盘聚焦时切换为省略号操作按钮。

## 交互规则

### 新建画布

1. 点击画布菜单标题栏中的“+”后，不立即调用 Store 创建画布。
2. 菜单列表顶部显示一个临时名称输入行，输入框自动聚焦并全选默认名称。
3. 默认名称使用无空格格式：`画布1`、`画布2`，并选择当前项目中尚未占用的最小正整数。
4. 用户按 Enter 或输入框失焦时提交创建。
5. 如果提交时输入值去除首尾空白后为空，则使用打开输入框时生成的默认名称。
6. 用户按 Escape 时取消临时输入，不创建画布，菜单保持打开。
7. 提交开始后关闭画布菜单，防止重复操作。

### 创建加载状态

1. 从提交开始到 Store 完成创建和切换期间，在画布上方显示全屏加载层。
2. 加载层复用项目库进入画布时的 `UniqueLoading` 九宫格动画、暗色背景和视觉层级。
3. 文案使用“正在创建画布”。
4. 创建成功后加载层淡出，用户看到新画布。
5. 创建失败时关闭加载层，保留原画布，并通过现有项目消息机制显示错误。
6. 加载期间禁止重复执行 Header 写操作，但不改变多窗口编辑锁协议。

### 当前画布与操作入口

1. 当前画布行右侧常驻显示 `Check` 图标，明确当前所在画布。
2. 当前画布行被鼠标悬停或键盘聚焦时，`Check` 隐藏，同一位置显示省略号操作按钮。
3. 非当前画布保留省略号操作入口。
4. 省略号按钮继续打开现有的“新窗口打开、重命名、复制、删除”二级菜单。
5. 当前标识和操作按钮占用固定宽度，避免名称或行布局在悬停时跳动。

## 组件与数据契约

### `CanvasSwitcher`

- 新增本地临时创建状态，包括默认名称、输入值和提交保护。
- `onCreateCanvas` 改为接收最终名称：`(name: string) => void | Promise<void>`。
- 临时输入不进入 `projectCanvases`，因此取消不会产生项目数据或保存操作。
- 现有重命名输入状态与新建输入状态互斥；关闭主菜单时清理二者。

### `InfiniteCanvas`

- 新建 Header 回调把确认后的名称传给 Store。
- 在现有 `canvasHeaderPending` 基础上增加仅用于画布创建的加载层可见状态。
- 复用 `runCanvasHeaderWriteAction` 的写锁检查、串行保护和错误处理。
- 加载层在异步操作的 `finally` 中收口，确保成功和失败都能结束。

### `canvas-store`

- `createCanvas` 改为 `createCanvas(name?: string): Promise<string>`。
- 有效的自定义名称经 trim 后作为画布名称保存。
- 未提供名称或名称为空时，使用统一默认名称 helper 生成 `画布N`。
- 保存、画布切换、撤销栈和 Agent 会话隔离行为保持不变。

### 默认名称 helper

- 更新现有画布名称分配逻辑，使新默认格式为 `画布N`。
- 识别项目中已有的 `画布N` 和历史 `画布 N`，避免迁移前后的默认名称发生编号碰撞。
- 不重命名已有画布，只影响之后创建的默认画布名称。

## 数据流

1. 用户点击“+”。
2. `CanvasSwitcher` 计算默认名称并展示临时输入。
3. Enter 或失焦提交最终名称；Escape 直接清理临时状态。
4. `CanvasSwitcher` 调用 `onCreateCanvas(finalName)`。
5. `InfiniteCanvas` 检查写锁，显示创建加载层，并调用 `createCanvas(finalName)`。
6. Store 保存当前脏画布，创建新画布文档和 manifest，再切换活动画布。
7. `InfiniteCanvas` 关闭加载层；成功显示新画布，失败显示错误并保留原状态。

## 错误与竞态处理

- 使用本地提交标志避免 Enter 与 blur 同时触发两次创建。
- Header 已有 pending 门控继续阻止并发的创建、复制、删除和重命名。
- 写锁处于 checking 或 blocked 时不能进入临时创建状态，也不能提交。
- 创建失败不向 `projectCanvases` 留下临时项。
- 菜单关闭、项目切换或组件卸载时清理临时输入状态。

## 验证

- `CanvasHeader.test.ts`：验证“+”只进入临时输入、Enter/blur 提交、空名称回退默认名、Escape 取消，以及当前项勾选与悬停省略号结构。
- `canvas-store-multi-canvas.test.ts`：验证自定义名称写入、空名称默认分配、`画布N` 与历史 `画布 N` 编号兼容。
- `InfiniteCanvas` 聚焦测试：验证创建名称透传、加载层文案与 finally 收口、写锁和 pending 门控保持生效。
- 运行 `npx tsc --noEmit`、`npm run lint`、`npm run build` 和 `git diff --check`。
- 在浏览器中复验菜单输入、失焦创建、Escape 取消、加载动画、当前勾选和悬停省略号。

## 非目标

- 不改变复制画布、重命名画布、删除画布和新窗口打开的产品规则。
- 不引入新的画布渲染器或新的全局加载组件。
- 不自动迁移或重命名已有的 `画布 1` 等历史名称。
