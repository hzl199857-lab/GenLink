# 快捷参考选择底部提示条设计

## 背景

GenLink 的文本、分镜脚本、图片生成、视频生成和音频生成节点都提供“快捷连接参考图/素材”入口。点击入口后，画布会进入 `quickReferenceConnect` 选择状态，但目前缺少持续可见的状态提示，也无法一键返回发起操作的节点。

本次改动为节点发起的快捷参考选择状态增加底部常驻提示条，并提供“返回节点”和“退出”操作。

## 目标

- 覆盖所有通过节点快捷参考按钮进入的选择状态。
- 进入状态后，在画布底部居中常驻显示操作提示。
- “返回节点”选中并平滑聚焦到发起快捷参考选择的节点，但不退出选择状态。
- “退出”立即结束选择状态并隐藏提示条。
- 保持现有参考素材选择、连线创建和选择完成后的退出行为不变。

## 非目标

- 不改变哪些节点可以作为图片、视频或音频参考素材。
- 不改变快捷参考连接生成的边结构和数据协议。
- 不迁移临时交互状态到 Zustand。
- 不为 Agent 面板的快捷画布参考选择显示“返回节点”提示条，因为该模式没有来源节点。

## 现有实现

相关实现集中在 `src/components/canvas/InfiniteCanvas.tsx`：

- `QuickReferenceConnectMode` 区分节点目标和 Agent 目标。
- 所有支持该功能的节点适配器都通过 `notifyQuickReferenceConnectRequest` 进入统一状态。
- `quickReferenceConnect` 保存当前快捷参考选择状态。
- `focusSingleNodeViewport` 已提供单节点平滑聚焦能力。
- `stopQuickReferenceConnect` 已提供统一退出能力。
- 来源节点被删除时，现有 effect 会自动清除节点目标的快捷参考状态。

## 交互设计

### 显示条件

当且仅当以下条件同时满足时显示底部提示条：

1. `quickReferenceConnect` 不为空。
2. `quickReferenceConnect.targetKind === 'node'`。
3. 来源节点仍存在；若不存在，现有清理逻辑会结束状态。

### 提示条内容

提示条固定在画布可视区域底部中央，不随 ReactFlow 视口缩放或平移：

- 状态图标。
- 文案“从画布选择参考”。
- 次级按钮“返回节点”。
- 主按钮“退出”。

视觉参考用户提供的深色圆角浮层：高对比文字、清晰按钮层级、足够高的 `z-index`，并避免遮挡画布底部边缘。

### 返回节点

点击“返回节点”后：

1. 使用 `selectSingleNode(targetNodeId)` 将来源节点设为当前选中节点。
2. 使用 `focusSingleNodeViewport(targetNodeId)` 平滑聚焦来源节点。
3. 不修改 `quickReferenceConnect`，因此提示条继续显示，用户仍可从画布选择参考素材。

### 退出

点击“退出”后调用 `stopQuickReferenceConnect()`：

- 清空快捷参考选择状态。
- 移除快捷选择样式和底部提示条。
- 不创建参考连线，不修改节点内容。

Escape 和右键退出继续沿用现有行为。

### 选择参考素材

成功选择合法参考节点后继续沿用现有流程：

- 创建参考连线或添加 Agent 附件。
- 结束快捷参考选择状态。
- 节点目标模式下选中来源节点。

本次不改变选择完成后是否额外聚焦视口的现有行为。

## 组件边界

提示条作为聚焦的画布 UI 组件放在 `src/components/canvas/` 下，由 `InfiniteCanvas` 传入：

- `onReturnToNode`
- `onExit`

组件只负责展示和触发回调，不读取 Zustand、不调用 ReactFlow，也不持有快捷参考状态。状态判断和画布操作仍由 `InfiniteCanvas` 负责，避免把无关职责继续堆入节点组件。

## 测试策略

- 组件测试或聚焦测试验证提示文案与两个操作按钮的回调行为。
- 纯逻辑测试验证仅节点目标模式显示提示条，Agent 目标模式不显示。
- TypeScript 检查确保联合类型收窄正确。
- 运行 `npx tsc --noEmit`。
- 运行 `npm run lint`。

## 验收标准

- 任一支持快捷参考连接的节点点击入口后，底部提示条立即出现。
- 平移或缩放画布时，提示条保持在可视区域底部中央。
- 点击“返回节点”后，来源节点被选中并平滑聚焦，提示条仍存在。
- 点击“退出”后，快捷参考选择状态和提示条同时消失。
- Escape、右键退出、成功选择参考素材、删除来源节点等现有退出路径保持正常。
- Agent 面板快捷选择画布参考图时不显示节点返回提示条。
