# Midjourney V8.1 傻瓜式参数面板设计

## 目标

将当前 Comfly 下的 `Midjourney` 模型改为面向普通用户的 `Midjourney V8.1`，隐藏不适用于 Midjourney 协议的通用图片参数，并通过中文预设和滑杆生成 Midjourney prompt 参数。

## 版本策略

- 内部模型 ID 继续使用 `midjourney`，避免破坏已有画布节点和历史数据。
- 用户界面显示 `Midjourney V8.1`。
- 每次 Imagine 请求固定追加 `--v 8.1`。
- Comfly 文档未确认 V8.1；如果上游不支持，保留并展示 Comfly 返回的参数错误，不静默降级到其他版本。

## 前端结构

选择 Midjourney V8.1 后，提示栏底部显示：

- `Midjourney V8.1` 模型标签。
- 当前宽高比，例如 `16:9`。
- Midjourney 高级设置按钮。
- 现有并行任务数控件，但文案明确为任务数；每个 Midjourney 任务仍返回一张四宫格。

以下通用控件在 Midjourney 模式隐藏：

- `1K / 2K / 4K`。
- `PNG / JPEG / WebP`。
- 通用内容审核 `auto / low`。
- 通用细节档位。

比例弹层只显示宽高比，不显示画质。继续沿用现有比例集合，并将非 `auto` 比例转换为 `--ar`。

## Midjourney 高级设置

高级设置使用中文预设加滑杆，默认值为：

| 参数 | UI 文案 | 默认 | 可选预设 | Prompt 参数 |
| --- | --- | --- | --- | --- |
| 风格化 | 风格化程度 | 100 | 低 50、默认 100、高 250、极高 750 | `--s` |
| 怪异度 | 怪异度 | 0 | 正常 0、轻微 100、明显 500 | `--weird` |
| 多样性 | 多样性 | 0 | 稳定 0、丰富 15、创意 35 | `--chaos` |
| Quality | 生成质量 | 1 | 标准 1、高质量 2 | `--q` |

滑杆范围：

- 风格化：0–1000，步长 10。
- 怪异度：0–3000，步长 50。
- 多样性：0–100，步长 1。
- Quality 使用二段选择，不使用连续滑杆。

节点数据增加可选字段保存以上参数，使画布快照、历史记录和重新生成保持一致。其他模型不读取这些字段。

## Prompt 组装规则

系统将用户输入拆成基础提示词和受管参数。受管参数包括：

- `--v` / `--version`
- `--ar` / `--aspect`
- `--s` / `--stylize`
- `--weird`
- `--chaos` / `--c`
- `--q` / `--quality`

如果用户手动输入了这些参数，系统先移除旧值，再按当前 UI 选择统一追加，避免同一参数重复或互相冲突。

示例：

```text
输入：portrait --v 6.1 --ar 1:1 --s 500
选择：V8.1、16:9、风格化 100、怪异度 0、多样性 15、质量 1
发送：portrait --v 8.1 --ar 16:9 --s 100 --weird 0 --chaos 15 --q 1
```

`auto` 比例不追加 `--ar`。数值使用整数并在服务端再次校验范围。

## 数据流

1. 用户选择 Midjourney V8.1。
2. 比例和高级参数写入 `ImageGenerationNodeData`。
3. 图片 API Route 从历史节点数据中读取 Midjourney 参数。
4. `buildMidjourneyPrompt` 清理旧受管参数并追加 V8.1 与 UI 参数。
5. Comfly Imagine 接口收到最终 prompt 和参考图 `base64Array`。
6. 后续四宫格与 U1～U4 流程保持不变。

## 错误处理

- 参数超出范围时在客户端归一化，并在服务端拒绝非法数据。
- V8.1 被 Comfly 拒绝时，显示上游错误，不自动改用 V6.1。
- 旧节点没有高级参数字段时使用默认值：风格化 100、怪异度 0、多样性 0、质量 1。
- 切换到其他模型时保留 Midjourney 参数但不显示、不发送，切回时恢复选择。

## 测试

- 模型显示为 `Midjourney V8.1`，内部 ID 仍为 `midjourney`。
- Midjourney 下隐藏通用画质、格式、审核和细节控件。
- 比例菜单只显示比例。
- 高级参数默认值、预设和滑杆范围正确。
- prompt 固定包含 `--v 8.1`。
- 手动输入的旧 `--v`、`--ar`、`--s`、`--weird`、`--chaos`、`--q` 被去重并由 UI 值覆盖。
- `auto` 不追加 `--ar`。
- 文生图和参考生图使用相同参数。
- 普通 Comfly 和其他 provider 行为不发生变化。
- 运行聚焦测试、`npx tsc --noEmit` 和 `npm run lint`。

## 完成标准

- 普通用户无需手写 Midjourney 参数即可选择比例、风格化、怪异度、多样性和质量。
- 红框中的无效通用控件不再出现在 Midjourney 模式。
- 所有 Midjourney 请求明确发送 V8.1。
- 现有四宫格选择高清图流程保持可用。
