# Midjourney 象限放大持续加载反馈设计

## 问题

用户点击四宫格中的一个象限发起 U1-U4 高清放大后，节点已经保存 `pendingQuadrant`，但加载徽标使用 `opacity-0`，仅在对应象限 hover 或键盘聚焦时显示。鼠标移开后没有持续反馈，容易被误认为任务卡住。

## 目标

在 Midjourney 高清放大任务完成或失败前，持续、明确地展示所选象限和任务进行状态，不依赖鼠标悬停。

## 交互与视觉

- 点击象限后，所选象限持续显示高亮边框和轻微深色遮罩。
- pending 状态不再显示左上角旋转加载图标，避免与中央加载图标重复。
- 所选象限中央显示“正在高清放大”状态文字和加载图标。
- 其他三个象限轻微变暗。
- 任务期间四个象限全部禁用，防止重复提交。
- 任务完成后，现有流程用高清单图替换四宫格。
- 任务失败后，现有状态逻辑清除 `pendingQuadrant`，恢复象限选择，并继续显示节点错误信息。

## 实现边界

- 复用现有 `pendingQuadrant` 和 `disabled` 属性，不新增持久化字段。
- 修改 `MidjourneyGridSelector.tsx` 的条件样式和持续加载内容。
- 不修改 API、轮询、U1-U4 action 映射或项目输出持久化流程。
- 保留非 pending 状态下的 hover 象限编号提示；左上角徽标仅用于显示 `1 / 2 / 3 / 4`。

## 验证

- 测试确认 pending 象限只显示中央加载图标，不渲染左上角加载图标。
- 测试确认选中象限具有持续高亮和 `aria-busy`。
- 测试确认其他象限在 pending 期间变暗，并且所有按钮禁用。
- 运行 Midjourney 聚焦测试、TypeScript、lint 和开发 bundle 检查。
