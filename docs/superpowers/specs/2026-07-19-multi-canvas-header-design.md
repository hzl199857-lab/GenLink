# 多画布与画布左上角控制器设计

日期：2026-07-19

## 目标

将画布左上角现有品牌与项目操作区域改造成紧凑的一体式“项目 / 画布控制器”，并为 GenLink 增加真实的项目内多画布能力。一个项目可拥有多个相互独立的画布，项目素材库保持共享，Agent 会话按画布隔离。

本次继续使用 ReactFlow 作为唯一画布运行时，不引入第二套画布渲染器。

## 已确认的产品行为

- 左侧保留 GenLink Logo，移除横向 Wordmark。
- 项目菜单包含“回到主页”“全部项目”“创建新项目”“删除项目”。
- “回到主页”进入 `/`；“全部项目”进入 `/?app=library`。
- 项目名称支持单击内联编辑。
- 一个项目包含多个画布，旧项目自动迁移为“画布 1”。
- 项目素材库与素材文件夹由所有画布共享。
- 节点、连线、分组、视口、撤销历史与 Agent 会话按画布隔离。
- 新建画布创建空白“画布 N”，创建成功后立即切换，不强制用户重命名。
- 复制画布复制节点、连线、分组与视口，不复制 Agent 会话。
- 删除画布前二次确认；最后一个画布禁止删除；删除画布不删除共享素材和生成文件。
- 不同窗口可以同时编辑同一项目的不同画布；同一画布同一时间只允许一个窗口编辑。

## 文件存储架构

项目目录采用清单与画布文档分离的结构：

```text
<project>/
├─ project.json
├─ canvases/
│  ├─ <canvas-id-1>.json
│  └─ <canvas-id-2>.json
├─ outputs/
└─ 现有素材、历史与缩略图目录
```

### 项目清单

`project.json` 保存项目级数据：

- 数据格式版本；
- 项目 ID、名称、创建与更新时间；
- 有顺序的画布元数据列表；
- 项目共享的素材文件夹与素材列表；
- 项目缩略图文件名。

画布元数据至少包含：

- `id`；
- `name`；
- `fileName`；
- `createdAt`；
- `updatedAt`。

当前画布不属于项目业务数据。最近打开的画布 ID 使用按用户和项目隔离的浏览器轻量存储保存，显式 URL 中的 `canvasId` 优先级更高。

### 画布文档

每个 `canvases/<canvas-id>.json` 独立保存：

- 画布 ID 与名称；
- 节点；
- 连线；
- 分组；
- ReactFlow 视口 `x`、`y`、`zoom`；
- 创建与更新时间。

节点产生的稳定输出文件仍使用现有项目输出与媒体存储 helper。画布文档不得持久化临时 `blob:` URL。

## 数据库结构

Prisma 增加 `Canvas` 模型，并建立 `Project -> Canvas -> CanvasNode / CanvasEdge` 的归属关系。节点与连线增加 `canvasId`，现有 `projectId` 可保留用于查询与归属校验。

旧数据库项目通过迁移创建默认画布，并将原节点、连线归入该画布。API mapper 必须在项目级共享数据和画布级数据之间做明确转换，不能继续假设项目只有一组平铺节点与连线。

## 旧项目迁移

加载旧版平铺 `ProjectSnapshot` 时：

1. 将原有节点、连线、分组写入新的默认画布文档；
2. 创建名称为“画布 1”的画布元数据；
3. 原素材文件夹、素材列表和项目缩略图继续留在项目清单；
4. 先写临时文件并重新读取校验；
5. 全部成功后再替换 `project.json`；
6. 失败时不覆盖旧文件，并以只读方式保留可恢复入口和中文错误提示。

不为已经废弃的中间格式添加长期兼容层，只支持当前旧格式到新格式的一次性迁移。

## Zustand 运行时

Store 保留现有 ReactFlow 消费的活动画布字段，避免大范围修改节点渲染链路，同时新增：

- 项目清单与画布元数据；
- `activeCanvasId`；
- 按画布保存的会话缓存；
- 画布创建、切换、重命名、复制、删除和新窗口打开动作。

每个画布会话缓存独立保存脏状态、撤销栈、重做栈、选择状态和视口。切换画布时先保存当前画布，再加载目标画布并恢复对应会话。保存失败时停止切换，不能丢弃当前未保存内容。

所有异步生成与写操作捕获启动时的 `userId + projectId + canvasId`。任务完成时必须校验作用域，只能更新原画布，不能因为用户已切换画布而污染新的活动画布。

## 多窗口与编辑锁

- 画布文件独立写入，因此不同画布可以并行编辑。
- 同一画布使用 Web Locks 获取独占编辑权。
- 使用 `BroadcastChannel` 发布占用、释放和心跳信息，并为不支持 Web Locks 的浏览器提供协调回退。
- 手动打开已被其他窗口占用的画布时显示占用状态，不进入可编辑运行时，并提供重试入口。
- 从当前窗口执行“在新窗口打开当前画布”时，先保存，再将编辑权移交给新窗口；原窗口显示该画布已在其他窗口打开，并允许切换到其他画布。
- 窗口异常退出后，心跳超时允许其他窗口重新获取编辑权。
- 项目清单、共享素材和项目名称等共享写入使用项目级串行锁。

## Agent 与 MCP 隔离

Agent 草稿、历史线程和当前线程的作用域从 `userId + projectId` 扩展为 `userId + projectId + canvasId`。

- 切换画布时切换对应 Agent 历史与草稿；
- 复制画布不复制 Agent 会话；
- 删除画布时删除该画布的 Agent 草稿和线程；
- MCP 与 OpenClaw 调用必须使用真实 `canvasId`，移除运行路径中的固定 `"default"`；
- 画布快照只包含目标画布的节点、连线、分组与运行摘要。

## 左上角组件

`CanvasHeader` 只负责组合与菜单互斥，聚焦职责拆分为：

- `ProjectMenu`：主页、项目库、新建项目、删除项目；
- `EditableProjectName`：项目名内联编辑；
- `CanvasSwitcher`：当前画布与画布列表；
- `CanvasItemMenu`：新窗口打开、重命名、复制、删除。

组件样式采用视频中的紧凑深灰色一体式圆角容器、低对比边框、灰阶悬停与短暂淡入淡出。保留 GenLink Logo，移除 Wordmark。项目现有字体、对话框和消息提示体系保持不变。

交互规则：

- 项目菜单与画布菜单互斥；
- 点击外部或按 Escape 关闭菜单；
- 展开时箭头翻转；
- 当前画布显示勾选，悬停后切换为省略号操作按钮；
- 画布名称和项目名称支持 Enter / 失焦提交、Escape 取消；
- 名称过长时截断，悬停显示完整名称；
- 画布操作菜单支持键盘导航与焦点恢复；
- “新建画布”按钮提供中文 Tooltip；
- 最后一个画布的删除项显示禁用状态。

## 画布操作

### 新建

生成稳定 ID，使用第一个未占用的“画布 N”名称，先创建空画布文件，再更新项目清单，成功后切换。

### 重命名

名称去除首尾空白，不允许空名称。保存失败时恢复旧名称并显示错误。

### 复制

使用新 ID 深拷贝节点、连线、分组与视口。需要为可能跨画布冲突的节点、连线和分组 ID 生成新 ID，并重写连线端点、分组成员以及节点数据中明确声明的内部引用。共享素材条目不复制。默认名称为“原名称 副本”，冲突时追加序号。

### 删除

二次确认后先从项目清单移除画布并保存，再清理画布文件和对应 Agent 本地状态。清理失败的文件作为孤立文件处理，项目清单不能继续引用它。共享素材和生成文件不删除。

## 错误处理与原子性

- 关键操作只有在磁盘写入成功后才提交 UI 状态；
- 画布文件使用临时写入与校验后替换；
- 项目清单不得指向不存在或无法解析的画布文件；
- 单个画布损坏不能阻止项目其他画布打开；
- 所有用户可见错误使用中文，并避免暴露本地绝对路径、文件句柄或敏感信息。

## 验证

- 数据 helper：命名、新建、复制、删除、顺序、旧格式迁移；
- Store：画布切换隔离、撤销栈隔离、视口恢复、异步任务作用域；
- 存储：项目清单与画布文件读写、失败原子性、素材共享；
- Agent：草稿和线程按 `canvasId` 隔离及删除清理；
- 多窗口：锁获取、主动移交、异常释放、不同画布并行；
- UI：菜单互斥、内联编辑、键盘操作、最后画布删除禁用；
- API / Prisma mapper：项目与画布归属转换；
- 完成后运行相关测试、`npx tsc --noEmit` 与 `npm run lint`。

## 非目标

- 不实现画布拖拽排序；
- 不实现画布回收站；
- 不复制 Agent 会话；
- 不删除共享素材或生成文件；
- 不引入实时多人协作；
- 不迁移 ReactFlow 渲染器。
