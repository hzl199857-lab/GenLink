# Ecom Image - 8 大类目专项细则

> 本文件是 `ecom-image/SKILL.md` 的领域知识库。`ecom-image` 在 Step 2 编排清单 / Step 3 Prompt Pack 必须按 `category` 字段加载本文件对应章节，作为"类目专项注入"。
>
> 每个类目按 5 维度组织：**场景重点（具象 / 抽象）/ 卖点重点 / 模特画像 / 细节重点 / 反模式**。所有内容应在 prompt content 字段以**具体视觉描述**呈现，不得堆砌抽象词（参 `_shared/image-aesthetic.md § 二`）。

---

## §1 数码 3C（digital3c）

适用品类：手机 / 耳机 / 笔记本 / 智能手表 / 智能设备 / 充电器 / 数据线 / 移动电源

### 1.1 场景图重点

- **具象场景**: 办公桌（极简白色桌面 + 笔记本 + 咖啡杯 + 自然窗光）/ 通勤地铁（深色座椅 + 暖色车灯）/ 居家书房（暖白光 + 木质桌面）
- **抽象场景**: 纯黑背景 + 蓝紫色光带从机身一侧扫过 / 几何反射光斑 / 深空灰渐变背景 + 单点蓝光打亮主体边缘 / 哑光金属台面 + 上方点光制造单点高光

### 1.2 卖点重点

屏幕亮度 / 边框工艺 / 接口数量 / 续航时长 / 处理器 / 摄像头规格 / 防水等级 / 重量 / 充电速度 / 兼容协议

### 1.3 模特画像

- 国内：年轻白领（男 25-35，商务休闲 / 女 22-30，知性时尚），数码爱好者
- 亚马逊：欧美 25-40，商务感 / 极客风都行；场景多用 home office / co-working space

### 1.4 细节重点

接口（USB-C / Lightning / 3.5mm 微距）/ 按键（材质 + 触感）/ 屏幕反射（45° 视角看屏边亮度）/ 散热孔 / Logo 蚀刻 / 边框 R 角

### 1.5 反模式

- 禁止用大量背景特效遮挡产品（粒子 / 烟雾不能压主体）
- 禁止屏幕显示自创内容（除非用户提供 UI 截图，否则用 black mockup screen）
- 禁止机身上加任何用户未提供的文字 / Logo

## §2 家用电器（appliance）

适用品类：大家电（冰箱 / 洗衣机 / 空调）/ 小家电（电饭煲 / 吹风机 / 加湿器）/ 清洁电器（吸尘器 / 扫地机 / 除螨仪）/ 厨电（破壁机 / 烤箱）/ 个护小家电（电动牙刷 / 剃须刀）

### 2.1 场景图重点

- **具象场景**: 现代厨房（白色橱柜 + 大理石台面 + 自然光）/ 客厅地板（浅木地板 + 柔软地毯）/ 阳台（白纱窗 + 散射光）/ 卫浴（白色瓷砖 + 暖白光）
- **抽象场景**: 浅灰渐变背景 + 主体居中悬浮 + 下方自然投影 / 暖白纯色背景 + 局部高光带打亮材质 / 哑光台面 + 主体侧上方主光

### 2.2 卖点重点

操作面板 / 内部结构剖视 / 工作状态可视化（吸尘器吸尘瞬间 / 加湿器水雾喷射 / 除螨仪集尘仓变化）/ 噪音分贝 / 容量 / 能效等级 / 滤芯 / 安装便捷性

### 2.3 模特画像

- 国内：年轻家庭（25-40 妈妈 / 爸爸 / 90 后小夫妻）/ 银发族（50-65 简洁居家）
- 亚马逊：欧美核心家庭，房型为 western kitchen / open living room

### 2.4 细节重点

操作面板按键 / 内部滤芯结构 / 工作中变化（蒸汽 / 水雾 / 集尘仓灰尘可视化）/ 接缝工艺 / Logo 与品牌色块

### 2.5 反模式

- 禁止过度的工作状态特效（夸张烟雾 / 不真实粒子）
- 禁止厨房 / 卫浴场景出现卫生问题（污渍 / 脏乱，除非用于"使用前对比"）
- 工作状态必须物理可信（吸尘器吸口下要有合理灰尘可视化路径，不能凭空飞）

## §3 服饰内衣（apparel）

适用品类：服装 / 内衣 / 睡衣 / 运动服 / 童装

### 3.1 场景图重点

- **具象场景**: 街拍（城市街道 / 弱透视 / 自然光）/ 衣帽间（暖光 + 衣架挂列 + 镜面）/ 户外（草地 / 海边 / 山间）/ 居家（白色布艺沙发 + 暖光）
- **抽象场景**: 浅灰 / 米白纯色背景 + 主体满构图 / 柔光散射 / 极简纯色背景 + 单光源勾勒服装轮廓与面料质感

### 3.2 卖点重点

面料质感（细致纤维纹理）/ 版型轮廓（修身 / 宽松 / A 字 / 直筒）/ 细节做工（车线 / 拉链 / 纽扣）/ 弹性 / 透气 / 抗皱 / 色牢度 / 适用季节

### 3.3 模特画像

- 国内：身材匀称 / 面部清爽，年龄按目标受众（少女系 18-22 / 都市白领 25-32 / 妈妈系 30-40）
- 亚马逊：多元化（白人 / 亚裔 / 黑人都可以），符合 Amazon Diversity Guidelines；身材接近真实而非极瘦
- 童装：自然亲子互动，避免独立小演员炫技

### 3.4 细节重点

面料微距特写（纹理 + 触感）/ 缝线工艺（车线密度 + 走线均匀度）/ 配件（纽扣 / 拉链头 / 织带 logo）/ 局部版型（领口 / 袖口 / 下摆收口）

### 3.5 反模式

- 禁止过度修图（皮肤蜡感 / 五官失真 / 肢体异常）
- 禁止过度展示某些敏感部位（按平台规则收口）
- 模特表情必须自然，避免僵硬 / 浮夸
- 童装禁止任何不当姿势 / 服装暴露

## §4 鞋靴箱包（shoebag）

适用品类：鞋类（运动鞋 / 高跟鞋 / 商务鞋 / 童鞋）/ 包袋（手提 / 单肩 / 双肩 / 钱包）/ 行李箱 / 配饰 / 帽子

### 4.1 场景图重点

- **具象场景**: 街拍场景（城市步道 / 通勤场景 / 时尚街区）/ 旅行场景（机场 / 酒店 / 度假目的地）/ 商务场景（办公室 / 酒店大堂）
- **抽象场景**: 浅灰渐变背景 + 主体 45° 角悬浮 / 自然投影 / 哑光台面 + 主体居中 + 侧上方主光

### 4.2 卖点重点

材质纹理（皮质 / 帆布 / 织物 / 网布微距）/ 内部结构（鞋内衬 / 包内分区）/ 五金件（拉链 / 扣具 / 提手金属件）/ 缓震 / 防滑 / 防水 / 容量 / 重量

### 4.3 模特画像

- 国内：时尚博主 / 商务人士 / 都市青年（按品类调整年龄段）
- 亚马逊：多元化 + 真实身材

### 4.4 细节重点

鞋底纹路 / 鞋面针脚 / 鞋头 / 内衬印花 / 包带连接 / 拉链头 / 包内分区 / 提手缝合 / 行李箱万向轮特写 / 把手伸缩

### 4.5 反模式

- 禁止过度反光导致材质失真
- 禁止把皮质做成塑料感（必须有自然褶皱 + 边缘高光层次）
- 禁止鞋类只展示单只（除非细节图，主图必须双只对称）

## §5 钟表珠宝（watchjewelry）

适用品类：手表 / 项链 / 戒指 / 手链 / 耳饰 / 宝石 / 头饰

### 5.1 场景图重点

- **具象场景**: 高端办公场景（深色实木桌面 + 名片夹 + 钢笔）/ 晚宴礼服佩戴（深色礼服一角 + 暖灯）/ 店面陈列（深色绒布 + 射灯）
- **抽象场景**: 黑色或深酒红绒布 + 单点射灯 / 哑黑亚克力台面 + 上方圆环柔光打出主体反光

### 5.2 卖点重点

表盘细节 / 指针工艺 / 表带（皮质 / 金属链 / 丝带）/ 镶嵌细节（宝石切面 / 镶口工艺）/ 防水深度 / 机芯（背透视图）/ 贵金属纯度 / 宝石克拉数

### 5.3 模特画像

- 国内：商务精英（男 30-45 / 女 28-40 优雅）/ 文艺女青年（25-35）
- 亚马逊：高端欧美男女，30-50

### 5.4 细节重点

表盘刻度（45° 微距）/ 指针倒角 / 表带链节 / 表冠 / 表背刻字 / 宝石切面反光 / 镶口爪 / 链扣闭合细节

### 5.5 反模式

- 禁止把宝石做成塑料颗粒感（必须有真实的折射 + 内部火彩）
- 禁止机械手表表盘加自创品牌（除非用户提供）
- 禁止用过度饱和的红 / 蓝色光（破坏奢华质感，应低饱和暖光）

## §6 美妆护肤（beauty）

适用品类：护肤品 / 化妆品 / 香水 / 彩妆工具 / 美容仪器

### 6.1 场景图重点

- **具象场景**: 梳妆台（白色梳妆台面 + 化妆镜 + 散落彩妆 + 自然窗光）/ 浴室（白色瓷砖 + 暖白光 + 毛巾）/ 卧室床头（暖光 + 浅色床品）
- **抽象场景**: 纯白 / 米白背景 + 局部主体悬浮 + 周围自然散落水滴 / 花瓣 / 粉末 / 浅粉渐变背景 + 主体居中 + 柔光

### 6.2 卖点重点

质地（涂抹瞬间 / 流动质感）/ 包装（玻璃 / 哑光 / 镭射）/ 使用涂抹瞬间（手背 / 脸颊 / 唇部）/ 成分图标 / 容量

### 6.3 模特画像

- 国内：肌肤细腻自然光感（不过度美白），25-35 为主，敏感肌产品可加 18-22 学生
- 亚马逊：多元化肤色，避免单一审美

### 6.4 细节重点

质地拉丝 / 涂抹瞬间皮肤反光 / 瓶口设计 / 喷头 / 滴管 / 内含物（如有展示）/ 包装表面工艺（烫金 / 浮雕）

### 6.5 反模式

- 禁止过度宣传功效（"祛斑 / 美白 / 抗衰"等需备案）
- 禁止把质地做成假感（流动应自然，黏稠度可信）
- 禁止模特皮肤过度修图（必须保留自然毛孔与细微肌理）

## §7 个护健康（personal_care）

适用品类：洗护（洗发水 / 沐浴露）/ 口腔护理（牙膏 / 牙刷 / 漱口水）/ 保健品 / 医疗器械（合规品类）

### 7.1 场景图重点

- **具象场景**: 浴室（白色瓷砖 + 干净洗漱台 + 暖白光）/ 卧室床头（暖光 + 简约床头柜）/ 居家厨房（保健品类，餐桌上 + 早餐场景）
- **抽象场景**: 浅蓝白渐变背景 + 主体居中（保健品 / 口腔类常用清洁感）/ 浅暖灰背景 + 主体单光源

### 7.2 卖点重点

使用过程（挤压瞬间 / 起泡 / 倾倒）/ 效果可视化（牙齿对比 / 头皮放松示意）/ 真实成分图标 / 适用人群标识 / 通过的认证标志

### 7.3 模特画像

- 国内：真实居家感 25-45，避免过度精致；保健品偏中老年（45-65）
- 亚马逊：欧美真实家庭感

### 7.4 细节重点

包装喷口 / 滴管 / 保健品胶囊 / 牙刷刷毛微距 / 真实使用瞬间（不过度摆拍）

### 7.5 反模式

- 禁止任何医疗暗示（"治疗 / 根治 / 治愈"）
- 保健品 prompt 必须能预留"本品不能代替药物"的文案位
- 医疗器械必须有备案号（用户须提供）
- 禁止用未成年人独立使用医疗器械

## §8 家居日用（home_living）

适用品类：厨具 / 收纳 / 家居装饰 / 文具 / 清洁用品 / 家纺

### 8.1 场景图重点

- **具象场景**: 开放式厨房 + 自然光 / 北欧客厅（浅木家具 + 白墙 + 绿植）/ 极简书桌 / 衣帽间收纳 / 卫浴收纳
- **抽象场景**: 浅灰 / 米白纯色背景 + 主体居中 + 柔光 / 浅木质感台面 + 上方暖白主光

### 8.2 卖点重点

使用场景演示 / 收纳整理过程（前后对比）/ 容量 / 材质环保性 / 工艺细节 / 多功能性

### 8.3 模特画像

- 国内：年轻居家生活感（25-40 全屋家居党 / 90 后小家庭）
- 亚马逊：欧美 home owner，多 DIY / lifestyle blogger 感

### 8.4 细节重点

接缝处理 / 表面材质（陶瓷釉面 / 木质纹理 / 不锈钢拉丝）/ 把手 / 接口 / 收纳分区 / 配件全家福

### 8.5 反模式

- 禁止"前乱后整"对比中前者过度脏乱（影响品牌调性）
- 禁止家居场景出现违和元素（北欧风里出现复古中式装饰等）
- 禁止把陶瓷做成塑料感（必须有釉面光泽与自然反光）

## §9 通用 / 跨类目（general）

当 `category=general` 或品类不明时，按通用产品图原则执行:

### 9.1 场景图

- 具象：浅木质 / 大理石台面 + 自然光 + 极简陪衬物
- 抽象：浅灰 / 米白纯色 + 主体居中 + 柔光

### 9.2 卖点

按用户提供的卖点字面执行，不做品类推断

### 9.3 模特

- 国内：25-35 都市白领
- 亚马逊：欧美 25-40

### 9.4 细节

按产品自然结构选 1-2 个最关键部位特写

### 9.5 反模式

- 禁止凭空补充产品功能 / 参数
- 禁止用户未指定的场景幻想
- 禁止"通用 = 平庸"，仍要遵循 image-aesthetic § 六默认审美增强策略

## §10 亚马逊适配通用规则（amazonMode=true 时叠加全部类目）

无论哪个 category，当 `platform=amazon` 或 `amazonMode=true`，都额外执行:

### 10.1 文案规则

- 卖点图、用户使用图、场景图字幕 / 标题 / 副标题**全部英文**
- 卖点表达符合 Amazon A+ Content 规范（feature bullets 风格）
- 数据宣传必须真实可查
- 禁止"健康疗效"宣称（受 FDA / FTC 限制）
- 禁止比较竞品（"better than X"）

### 10.2 模特规则

- 默认欧美（白人 / 拉美 / 亚裔 / 黑人按目标市场分布）
- 多元化（推荐至少 1 张图含非白人模特）
- 真实身材（避免过度修图）

### 10.3 场景规则

- 西式厨房（gas stove / island / pantry）/ 独立卫浴（bathtub / 双台盆）/ Carpet 客厅
- 测量单位英制（inch / lb / fl oz / °F）
- 房型符合美式 / 欧式独栋或公寓

### 10.4 色彩偏好

- 偏明亮干净（white / light wood / pastel accents）
- 避免过度国风元素（红色印章 / 水墨）
- 主图严格白底（Amazon main image 强制要求）

### 10.5 排版偏好

- A+ Content: 左右分栏 + 大图 + 简短英文卖点
- Brand Story: 横向滚动 + 品牌叙事
- 所有文字版位预留充足留白（文字面积控制在 30% 以内）
